Ask the record

A live agent over a public Sanity dataset of 120 documents — 74 published articles, 14 defects outside engineers found in my work, and the claims those produced. It answers from the record or says it cannot. No login. Keys stay on the server.
Project u58x3mt0 · public dataset · Studio

Questions are fixed: these are the five an independent reviewer graded, so what you see is what was tested.
Identifier lookups route to a GROQ endpoint; prose questions route to a Knowledge Base. The badge shows which one answered.
Every answer is checked against the same output contract the independent reviewer graded. If one is missing a required field, has empty uncertainty, or fails the citation requirement for the instrument that produced it, this page shows the violation instead of rendering the answer cleanly. It checks that citations are present and well formed; it does not fetch them.
